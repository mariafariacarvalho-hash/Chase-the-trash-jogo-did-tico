# Chase-the-trash-jogo-did-tico# 🗑️ Metro Recicla

Jogo de corrida infinita estilo **Subway Surfers** com temática de **reciclagem**.
Controle um lixeiro pelos trilhos do metrô, desvie de obstáculos e colete materiais recicláveis!

## 🎮 Como Jogar

- ⬅️ / ➡️ ou **A/D** → trocar de faixa
- ⬆️ / **W** / **Espaço** → pular obstáculos
- **Swipe** no celular → esquerda/direita para desviar, cima para pular

## ✨ Recursos

- 🎨 Visual neon com perspectiva de trilhos
- ♻️ 4 tipos de recicláveis (plástico, papel, vidro, metal)
- 🚧 3 tipos de obstáculos (barreira, saco de lixo, cone)
- ⚡ Velocidade progressiva
- 🏆 Recorde salvo no `localStorage`
- 📱 Suporte a touch/swipe

## 🚀 Como Executar

Basta abrir o `index.html` em qualquer navegador moderno — sem build, sem dependências!

## 🛠️ Tecnologias

- HTML5 Canvas
- JavaScript puro (ES6+)
- CSS3 (glassmorphism + neon glow)
